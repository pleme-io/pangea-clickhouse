ClickHouse Cloud provider resources for the Pangea infrastructure DSL. All
resource code is **auto-generated** by `pangea-forge` via
`terraform-schema-importer`. Manual edits to resource files will be overwritten
on the next generation run.

## Structure

```
lib/
  pangea-clickhouse.rb                # Entry point (generated -- requires all resources)
  pangea-clickhouse/version.rb        # Version constant (manual)
  pangea/
    resources/
      clickhouse.rb                   # Aggregator module (generated)
      clickhouse_*/                   # 30 resource directories (generated)
        types.rb                      # Dry::Struct attributes class
        resource.rb                   # ResourceBuilder DSL
sig/                                  # RBS signatures (generated)
profiles/                             # InSpec profiles (generated)
spec/
  spec_helper.rb                      # Test setup (manual)
  support/                            # Shared test helpers
  resources/                          # RSpec stubs (generated)
```

## Generated vs Manual

| File | Source |
|------|--------|
| `lib/pangea/resources/clickhouse_*/` | Generated by pangea-forge |
| `lib/pangea-clickhouse.rb` | Generated (require file) |
| `lib/pangea/resources/clickhouse.rb` | Generated (aggregator) |
| `sig/`, `profiles/`, `spec/resources/`, `spec/support/shared_examples.rb` | Generated |
| `lib/pangea-clickhouse/version.rb` | Manual |
| `spec/spec_helper.rb`, `spec/support/synthesis_test_helpers.rb` | Manual |
| `Gemfile`, `*.gemspec`, `flake.nix` | Manual |

The Ruby module is `Pangea::Resources::Clickhouse` (pangea-forge's default
PascalCase for the `clickhouse` provider name); methods are `clickhouse_*`.

## Regeneration

The provider binary is packaged by `blackmatter-clickhouse`
(`pkgs/terraform-provider-clickhouse.nix`). Build OpenTofu with it, dump the
schema, then regenerate:

```sh
tofu init && tofu providers schema -json > schema.json
terraform-schema-importer generate \
  --schema schema.json \
  --provider "registry.opentofu.org/clickhouse/clickhouse" \
  --provider-name clickhouse \
  --output-dir . \
  --verify
```

OpenTofu keys the schema as `registry.opentofu.org/clickhouse/clickhouse`;
with Terraform it is `registry.terraform.io/clickhouse/clickhouse`.
